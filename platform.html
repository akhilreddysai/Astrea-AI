03

Governance

Why the numbers hold up.

Run ID and hash

Every value carries a run ID and a SHA-256 hash of the inputs that produced it. Any figure in any report can be regenerated.

Gated model swaps

No model reaches production without passing a regression suite of more than fifty scenarios, with signed validation for each upgrade.

Analyst in the loop

A person verifies the causal links the system proposes. Attribution is reviewed, not asserted.
