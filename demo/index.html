About this demo

This page runs on a fixed extract of the Danish day-ahead record so it can be read without a login. The production system refreshes daily, scores every call against settlement, and exposes the same view through an API. Figures are daily-mean day-ahead prices in €/MWh, from a one-day-ahead hindcast of the deployed model on forecast-weather inputs.
